- **`<ListRow />` primitive** — the three consumers (TaskRow,
  calendar/TaskList, BoardCard) have genuinely different interaction
  models: sortable-always-on vs optional, text-meta vs pill badges vs
  EditableCell, different completion animations. Forcing a common API
  without UX-ownership would trade code dedup for API bloat or lost
  distinctiveness. Needs a dedicated design+migration session.

  first, in order: employees, financials, budgets, customers, projects.

  has never been pushed. Rotation is hygiene, not an active leak.
