## Open audit items not yet resolved

From the 8-agent sweep on 2026-04-20:

**Backend (beyond fix/backend-p0-batch):**
- `auditLog` called after `res.json()` in `routes/wiki.js` — a throw there is unhandled because the response is already committed. Move before `res.json()` or wrap.
- `routes/calendar.js:188` leaks raw Google API error strings to the client.
- `recomputeScenarios` (`routes/projects.js:261`) loops per-scenario without a transaction; partial failure leaves inconsistent state.
- `validateBody` middleware doesn't reject `__proto__` / `constructor` / `prototype` top-level keys.
- 6 hot-path missing indexes: `tasks(field_id)`, `tasks(enterprise)`, `calendar_events(start_date)`, `calendar_events(enterprise)`, `livestock_records(group_id, date DESC)`, `processing_steps(batch_id, step_number)`.
- 7 FKs missing `ON DELETE CASCADE` / `SET NULL` (only `fields.farm_id` was fixed): `livestock_groups.current_field_id`, `breeding_seasons.group_id`, `shearing_records.group_id`, `inventory_transactions.product_id`, `financial_transactions.enterprise_id`, `budgets.enterprise_id`, `time_entries.task_id`.
- `seed-wiki.js` partial-seed poisoning (no transaction wrap).

**Frontend (beyond Phases 0–5):**
- `WikiRenderer.tsx:295` DOMPurify config allows `style` and `input` — remove from `ALLOWED_ATTR` / `ALLOWED_TAGS`.
- `WikiRenderer.tsx:208` mermaid SVG injected via `innerHTML` without sanitization — pipe through DOMPurify SVG profile.
- No `aria-live` region for QuickAddFAB / completion undo toasts *not migrated to useToast yet*.
- No focus trap inside `ProjectModal` / `TaskEditor` / `TaskDetailSheet` (return-focus is in place; trap is not).
- `window.confirm()` still in use: `AnnotationsSidebar.tsx` (×3), `hooks/useMapData.ts:145`, `hooks/useAnnotationState.ts:232` (`window.alert`).
- `TS6133` / `TS2322` pre-existing build-blockers in `TodayView.tsx`, `TaskDetailSheet.tsx`, `TaskRow.tsx`, `InlineTaskAdd.tsx`, `useMapInteractions.ts`, `TaskManagerPage.tsx:35` (the `TS2322` on TaskManagerPage was fixed in `0efb3f2`; rest remain). `npm run build` fails until these are cleaned up.
- Dashboard bundle-split: MapLibre imported eagerly but only used on `/map`. Motion library eagerly loaded. Lazy-route these.
